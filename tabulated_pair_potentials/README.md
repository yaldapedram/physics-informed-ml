# Na-MMT GPR + Morse Potentials

This repository contains tabulated 2-body interaction potentials (GPR + Morse) for Na-MMT coarse-grained simulations.

**Files:**
- `center_center.txt`
- `edge_center.txt`
- `edge_edge.txt`

These files are intended for use in mesoscale simulation scripts, such as the Young’s modulus.
